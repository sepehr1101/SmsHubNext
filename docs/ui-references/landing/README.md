# Landing page reference

`smshub-landing-reference.html` is an unchanged copy of the first visual reference supplied by the product owner on 2026-10-11.

`smshub-landing-reference-v2.html` is the complete second reference and is now the primary visual direction for the landing page.

The supplied HTML ends midway through its hero dashboard markup and does not contain a closing document or the later sections described by its CSS. It is therefore a visual direction rather than runnable source. The Blazor implementation lives under `src/SmsHubNext/Features/Landing/Ui` and adapts the copy to capabilities that actually exist in SmsHubNext.
