# API مشاهده خطاهای HTTP

`GET /logging/errors` با توکن Bearer مدیر، پاسخ‌های ناموفق صادرشده از میزبان برنامه را نمایش می‌دهد. این API خطاهای HTTP پاسخ‌داده‌شده به کلاینت را گزارش می‌کند؛ وضعیت سرویس بیرونی پیامک در صورتی دیده می‌شود که به پاسخ HTTP برنامه تبدیل شده باشد.

پارامترها:

| پارامتر | توضیح |
| --- | --- |
| `statusClass` | الزامی: `4xx` یا `5xx`؛ حروف بزرگ نیز پذیرفته می‌شود |
| `fromDate`, `toDate` | الزامی: تاریخ میلادی `yyyy-MM-dd`، روزهای تقویمی ساعت تهران؛ حداکثر ۳۱ روز با احتساب دو سر بازه |
| `fromTime`, `toTime` | اختیاری، هر دو با هم: ساعت `HH:mm:ss` یا `HH:mm` تهران؛ برای هر روز بازه اعمال می‌شود |
| `statusCode` | اختیاری: کد دقیق در گروه انتخاب‌شده، مثلاً `401` |

کلاینت فارسی تاریخ انتخاب‌شده شمسی را پیش از ارسال به تاریخ میلادی تبدیل می‌کند. دو سر بازه ساعت شامل هستند؛ بدون ساعت، تمام ساعات روزها جست‌وجو می‌شوند. اگر ساعت شروع از پایان بزرگ‌تر باشد، بازه شبانه اعمال می‌شود: `22:00` تا `02:00` یعنی ساعات ۲۲ تا پایان روز و شروع روز تا ۰۲ در هر روز انتخاب‌شده.

مثال:

```http
GET /logging/errors?statusClass=4xx&fromDate=2026-11-01&toDate=2026-11-03&fromTime=08:00&toTime=18:00
Authorization: Bearer <administrator-token>
```

پاسخ در پوشش استاندارد `ApiResponse` برمی‌گردد. `data.items` شامل `timestamp` با offset، `statusCode` دقیق، `method`، `path` و `traceId` است؛ جدیدترین رخداد اول است. `truncated` نشان می‌دهد بیش از ۱۰۰۰ نتیجه وجود داشته و فقط ۱۰۰۰ رخداد جدیدتر برگشته است. `skippedLines` تعداد خطوط JSON خراب را نشان می‌دهد. فیلترها پیش از محدودکردن نتایج اعمال می‌شوند. بازه یا فیلتر نامعتبر پاسخ ۴۰۰، نبود توکن پاسخ ۴۰۱ و دسترسی غیرمدیر پاسخ ۴۰۳ می‌دهد.

ثبت با Serilog در فایل‌های روزانه `http-errors-*.jsonl` زیر مسیر `ApplicationLogs:DirectoryPath` انجام می‌شود؛ هر فایل حداکثر ۳۲ مگابایت و نگهداری حداکثر ۶۲ فایل است (تعداد فایل، نه تضمین ۶۲ روز). داده‌های قبل از این تغییر قابل بازیابی نیستند. پاسخ‌های تولیدشده قبل از ورود به برنامه، مثلاً توسط IIS یا پراکسی، در این فایل‌ها نیستند. بدنه، query string، رمز و هدر Authorization ذخیره نمی‌شوند. فایل‌های خطاهای داخلی برنامه همچنان جداگانه نگهداری می‌شوند.
