# ظاهر بخش مدیریت

جهت مورد تأیید کاربر در ۲۰۲۶/۱۱/۰۱: بهتر نمایش‌دادن قابلیت‌های موجود، بدون تغییر مسیرها، رفتار کنترل‌ها، داده‌ها یا قواعد ارسال و حسابداری.

## جهت بصری

پنل عملیاتی فارسی برای اپراتور پیامک و حسابداری. ENERGY 1 / RHYTHM 1 / MOTION 1: آرام، قابل پیش‌بینی، با بازخورد حرکت فقط در تعامل. هویت موجود از Vazirmatn، ارقام فارسی، دوره‌های شمسی، ستون‌های مالی و ناوبری سرمه‌ای می‌آید. رنگ آبی برای اقدام و پیوند؛ سبز، کهربایی و قرمز فقط برای معنای وضعیت. تم و مسیر ناوبری موجود حفظ می‌شوند.

- جدول، فرم یا روند عملیاتی نقطهٔ اصلی صفحه است. میان‌برهای پیمایش ارتفاع محتوایی دارند تا کار روزانه به پایین صفحه رانده نشود.
- خلاصه‌های عددی یک نوار مشترک با جداکننده‌اند؛ برای هر عدد یک کارت شناور ساخته نمی‌شود. در عرض میانی و موبایل دو ستون دارند و در دسکتاپ چهار ستون.
- پنل مستقل شعاع ۸، کنترل شعاع ۶ و برچسب وضعیت شعاع کوچک دارد؛ شکل‌ها نقش‌های متفاوت را نشان می‌دهند.
- سایه فقط برای نوار اقدام چسبان و لایه‌های شناور باقی می‌ماند؛ بخش‌های صفحه روی سطح ثابت‌اند.
- آیکن‌های موجود برای تشخیص مقصد و عمل حفظ می‌شوند؛ قاب و زمینهٔ تزئینی آن‌ها کاهش می‌یابد.
- مسیر صفحه بدون کارت جدا نمایش دارد؛ عنوان اصلی خواناتر است. تیتر تکراری در صفحهٔ خطاها و جست‌وجوی پیامک حذف شده است.
- رنگ‌های ردیف جدول همان `#f3f6fa` و `#e9f0f8` هستند. جست‌وجو، فیلتر، اکسل، انتخاب ستون و فرم‌ها تغییر رفتاری ندارند.

## محدودهٔ اجرا

لایهٔ `admin-refinement.css` فقط زیر `.admin-refined` اعمال می‌شود؛ سایت عمومی و محتوای دیالوگ‌ها از آن مستقل‌اند. این لایه با حذف کلاس یا پیوند stylesheet قابل برگشت است. بازنویسی CSS قدیمی و اصلاح منطق قابلیت‌ها جزو این تغییر نیست.
